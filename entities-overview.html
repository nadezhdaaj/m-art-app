Сущности системы m-art-app (backend: mart-backend, Prisma)

Ниже перечислены сущности (таблицы базы данных) из mart-backend/prisma/schema.prisma, которые реально используются в коде backend (mart-backend/index.js, prisma/seed.js). Каждая сущность снабжена описанием назначения и таблицей полей.

1. User — Пользователь

Назначение: учётная запись пользователя приложения. Хранит данные для входа, профиль (имя, аватар, биография), а также игровые показатели — баллы и звание. Используется в маршрутах регистрации/входа (/auth/register, /auth/login, /auth/sign-in/email, /auth/sign-up/email, /auth/get-session) и профиля (/profile/me, /profile/:id, /profile/:id/add-points).

ПолеТипОписание
idString (UUID)Идентификатор пользователя
emailString (уник.)Email, используется для входа
passwordHashStringХэш пароля
usernameString?Имя пользователя (никнейм)
avatarUrlString?Ссылка на аватар
bioString?Краткая биография / описание профиля
pointsIntОбщее количество накопленных баллов
quiz1PointsIntБаллы, набранные в викторине
titleStringЗвание пользователя (например, «Новичок»), присваивается по уровню баллов
createdAt / updatedAtDateTimeДаты создания и обновления записи

2. Artwork — Творческая работа пользователя

Назначение: работа (рисунок), созданная пользователем в приложении (например, в графическом редакторе). Хранит изображение, статус и метаданные. Используется в маршрутах /artworks/me, /artworks/me/:id (получение, создание, обновление работ).

ПолеТипОписание
idString (UUID)Идентификатор работы
userIdStringСсылка на автора работы (User)
title / descriptionString?Название и описание работы
kindStringТип работы (по умолчанию «painting»)
sourceStringИсточник создания (по умолчанию «paint-canvas»)
statusStringСтатус работы (по умолчанию «DRAFT»)
schemaVersionIntВерсия формата хранения данных работы
imageUrl / thumbnailUrlString / String?Ссылки на изображение и его миниатюру
createdAt / updatedAtDateTimeДаты создания и обновления работы

3. QuizQuestion — Вопрос викторины

Назначение: вопрос викторины с пояснительным фактом и индексом правильного ответа. Используется в маршрутах /quiz/questions (получение списка вопросов с вариантами ответов) и /quiz/add (добавление нового вопроса), а также при наполнении базы тестовыми данными (seed.js).

ПолеТипОписание
idString (UUID)Идентификатор вопроса
questionString (уник.)Текст вопроса
factStringПояснительный факт, показываемый после ответа
correctIndexIntИндекс правильного варианта ответа в списке
createdAtDateTimeДата создания вопроса

4. QuizAnswer — Вариант ответа

Назначение: вариант ответа, привязанный к конкретному вопросу викторины. Создаётся вместе с вопросом и возвращается вместе с ним при запросе списка вопросов (включается через связь answers в маршруте /quiz/questions и /quiz/add).

ПолеТипОписание
idString (UUID)Идентификатор варианта ответа
textStringТекст варианта ответа
questionIdStringСсылка на вопрос (QuizQuestion)

5. ExhibitFavorite — Избранный экспонат

Назначение: отметка «избранное» — связывает пользователя с экспонатом (внешним идентификатором), который он добавил в избранное. Используется в маршрутах /favorites/exhibits (список, добавление через upsert, удаление избранного).

ПолеТипОписание
idString (UUID)Идентификатор записи
userIdStringСсылка на пользователя (User)
exhibitIdStringИдентификатор экспоната (внешний, не связан напрямую таблицей)
createdAtDateTimeДата добавления в избранное

Уникальное ограничение [userId, exhibitId] — пользователь не может добавить один и тот же экспонат в избранное дважды.

6. ExhibitView — Просмотр экспоната

Назначение: фиксирует факт просмотра пользователем конкретного экспоната — используется для отслеживания прогресса осмотра коллекции. Применяется в маршрутах /progress/exhibits/views (список просмотренных экспонатов) и /progress/exhibits/:exhibitId/view (отметка о просмотре).

ПолеТипОписание
idString (UUID)Идентификатор записи
userIdStringСсылка на пользователя (User)
exhibitIdStringИдентификатор экспоната (внешний, не связан напрямую таблицей)
createdAtDateTimeДата первого просмотра экспоната

Уникальное ограничение [userId, exhibitId] — повторный просмотр того же экспоната не создаёт новую запись.
