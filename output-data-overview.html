Выходные данные приложения M-ART

Обзор данных, которые система возвращает клиенту (Unity-приложению) через REST API бэкенда (mart-backend/index.js), а также то, что в итоге видит пользователь на экране.

ПолеТипЭндпоинтОписание
tokenстрока (JWT)POST /auth/register, /auth/login, /auth/sign-up/email, /auth/sign-in/emailТокен авторизации, выдаваемый после входа/регистрации
id, username, email, avatarUrl, bioстроки*/auth/*, GET /auth/get-sessionДанные профиля пользователя в составе ответа
points, titleчисло, строка*/auth/*, профильТекущие очки и звание пользователя («Новичок», «Мастер галереи» и т.д.)
createdAt, updatedAtдата/время*/auth/*Метки создания и обновления учётной записи
messageстрокаЛюбой эндпоинт при ошибкеТекстовое сообщение об ошибке (напр. «User not found», «Invalid password»)

Таблица 8 — Выходные данные на стороне Unity-приложения

Что выводитсяОписание
Экраны интерфейсаВизуальное отображение данных, полученных от backend API (профиль, галерея, редактор, выставки, викторина, чат с гидом)
Холст / нарисованное изображениеРезультат работы пользователя в графическом редакторе (paint-canvas), который затем отправляется на сервер как image/thumbnail
Уведомления и всплывающие сообщенияОбратная связь по действиям пользователя (успех операции, ошибки, начисление очков/опыта)
Звуковые и анимационные эффектыРеакция интерфейса на действия пользователя (геймификация, прогресс, достижения)
