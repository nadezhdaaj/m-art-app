# Выходные данные приложения M-ART

Обзор данных, которые система возвращает клиенту (Unity-приложению) через REST API бэкенда ([mart-backend/index.js](mart-backend/index.js)), а также то, что в итоге видит пользователь на экране.

## Таблица 1 — Аутентификация и сессия

| Поле | Тип | Эндпоинт | Описание |
|---|---|---|---|
| token | строка (JWT) | `POST /auth/register`, `/auth/login`, `/auth/sign-up/email`, `/auth/sign-in/email` | Токен авторизации, выдаваемый после входа/регистрации |
| id, username, email, avatarUrl, bio | строки | `*/auth/*`, `GET /auth/get-session` | Данные профиля пользователя в составе ответа |
| points, title | число, строка | `*/auth/*`, профиль | Текущие очки и звание пользователя («Новичок», «Мастер галереи» и т.д.) |
| createdAt, updatedAt | дата/время | `*/auth/*` | Метки создания и обновления учётной записи |
| message | строка | Любой эндпоинт при ошибке | Текстовое сообщение об ошибке (напр. «User not found», «Invalid password») |

## Таблица 2 — Профиль пользователя

| Поле | Тип | Эндпоинт | Описание |
|---|---|---|---|
| id, userId | строка (UUID) | `GET/PATCH /profile/me`, `/profile/:id` | Идентификатор пользователя |
| displayName | строка | `GET/PATCH /profile/me` | Отображаемое имя (username или email) |
| bio, avatarUrl | строки | `GET/PATCH /profile/*` | Биография и ссылка на изображение аватара |
| progress.xp | строка (число) | `GET/PATCH /profile/me` | Текущий опыт пользователя в виде вложенного объекта `progress` |
| points, title | число, строка | `GET /profile/:id`, `POST /profile/:id/add-points` | Накопленные очки и присвоенное звание |

## Таблица 3 — Произведения искусства (Artwork)

| Поле | Тип | Эндпоинт | Описание |
|---|---|---|---|
| id | строка (UUID) | `GET/POST/PATCH /artworks/me*` | Идентификатор произведения |
| title, description | строки | `GET/POST/PATCH /artworks/me*` | Название и описание произведения |
| kind, source, status | строки | `GET/POST/PATCH /artworks/me*` | Тип, источник создания и статус (`DRAFT`, и т.д.) |
| schemaVersion | число | `GET/POST/PATCH /artworks/me*` | Версия схемы данных |
| imageUrl, thumbnailUrl | строка (URL) | `GET/POST/PATCH /artworks/me*` | Полные ссылки на изображение и миниатюру (формируются на основе `publicBase`) |
| publishedAt, createdAt, updatedAt | дата/время | `GET/POST/PATCH /artworks/me*` | Метки публикации, создания и обновления |
| список произведений | массив объектов Artwork | `GET /artworks/me` | Список всех работ текущего пользователя |

## Таблица 4 — Избранное и просмотры экспонатов

| Поле | Тип | Эндпоинт | Описание |
|---|---|---|---|
| список exhibitId | массив строк | `GET /favorites/exhibits`, `GET /progress/exhibits/views` | Идентификаторы избранных / просмотренных экспонатов |
| exhibitId, createdAt | строка, дата | `POST /favorites/exhibits/:exhibitId` | Подтверждение добавления экспоната в избранное с датой |
| ok | булево | `DELETE /favorites/exhibits/:exhibitId` | Подтверждение удаления из избранного |
| applied | булево | `POST /progress/exhibits/:exhibitId/view` | Признак того, был ли просмотр зафиксирован впервые |
| awardedXp, previousXp, totalXp | числа | `POST /progress/exhibits/:exhibitId/view` | Начисленный опыт, опыт до и после начисления (геймификация) |

## Таблица 5 — Гид (чат-помощник)

| Поле | Тип | Эндпоинт | Описание |
|---|---|---|---|
| welcome, suggestions | строка, массив | `GET /guide/suggestions` | Приветственный текст и подсказки-чипы для начала диалога |
| reply | строка | `POST /guide/chat` | Ответ гида (Мартишки) на сообщение или выбранную тему |
| topicId | строка или null | `POST /guide/chat` | Идентификатор распознанной темы беседы |
| source | строка (`chip`, `keyword`, `off_topic`, `no_match`) | `POST /guide/chat` | Источник/способ формирования ответа |

## Таблица 6 — Викторина (Quiz)

| Поле | Тип | Эндпоинт | Описание |
|---|---|---|---|
| список вопросов | массив объектов QuizQuestion | `GET /quiz/questions` | Вопросы викторины вместе с вариантами ответов (`answers`) |
| question, fact, correctIndex | строки, число | `GET /quiz/questions`, `POST /quiz/add` | Текст вопроса, пояснительный факт и индекс правильного ответа |
| answers | массив объектов QuizAnswer | `GET /quiz/questions`, `POST /quiz/add` | Варианты ответов на вопрос |

## Таблица 7 — Файлы и медиа

| Данные | Тип | Где формируется | Описание |
|---|---|---|---|
| файл аватара | изображение (статика) | `/uploads/avatars/...` | Загруженное и сохранённое изображение профиля, отдаётся по прямой ссылке |
| файл произведения / миниатюра | изображение (статика) | `/uploads/artworks/...` (через `imageUrl`/`thumbnailUrl`) | Сохранённое изображение работы и его уменьшенная копия |

## Таблица 8 — Выходные данные на стороне Unity-приложения

| Что выводится | Описание |
|---|---|
| Экраны интерфейса (профиль, галерея, редактор, выставки, викторина, чат с гидом) | Визуальное отображение данных, полученных от backend API |
| Холст / нарисованное изображение | Результат работы пользователя в графическом редакторе (`paint-canvas`), который затем отправляется на сервер как `image`/`thumbnail` |
| Уведомления и всплывающие сообщения | Обратная связь по действиям пользователя (успех операции, ошибки, начисление очков/опыта) |
| Звуковые и анимационные эффекты | Реакция интерфейса на действия пользователя (геймификация, прогресс, достижения) |
