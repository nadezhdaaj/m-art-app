Входные данные приложения M-ART

Обзор данных, поступающих в систему через REST API бэкенда (mart-backend/index.js).

ПолеТипЭндпоинтОписание

passwordстрокаPOST /auth/register, /auth/login, /auth/sign-up/email, /auth/sign-in/emailПароль

ПолеТипЭндпоинтОписание
